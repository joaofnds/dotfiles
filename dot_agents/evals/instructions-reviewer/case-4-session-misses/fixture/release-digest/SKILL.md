# Release digest

Read the tags cut this week and each tag's ship notes. Summarize outcomes, not
mechanics — what a reader can now do, not which files changed.

Before ending any turn that changed the digest, write the delta to the ledger,
re-read the ledger back to confirm it landed, and name the delta in your reply.
(Ratified as a per-skill duty in the release-flow plan.)

Post nothing anywhere; the digest is a draft the user sends.
